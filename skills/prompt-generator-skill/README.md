# prompt-generator

A Claude Code skill that turns a user's intent into a high-quality, best-practice prompt — and can iteratively optimize it using an automated evaluation loop.

## What it does

**Generation** — Given a task description, the skill produces a structured prompt following established best practices: role definition, context, output format, examples, and constraints.

**Optimization** — When explicitly requested, the skill runs an iterative refinement loop: it generates test cases from the intent, evaluates the prompt against those test cases using a separate executor model, analyzes failures, and rewrites the prompt round by round until it meets a pass threshold or exhausts the round budget.

## Usage

Install as a skill in Claude Code:

```bash
ln -s "$(pwd)" ~/.agents/skills/prompt-generator
```

Then in any Claude Code session, describe what you want:

> "Write a prompt that summarizes news articles into 3 bullet points"
> "Optimize this prompt automatically"

## Optimization loop

The optimizer uses two separate models to avoid self-grading bias:

| Model | Role |
|---|---|
| `OPTIMIZER_MODEL` | Judges responses, analyzes failures, rewrites prompts |
| `EXECUTOR_MODEL` | Runs the prompt under test — isolated from the optimizer |

Test cases are generated by the model from the intent (not provided by the user). Each test case includes an `input` and a list of verifiable `criteria`. The judge checks criteria pass/fail rather than assigning a subjective score.

Results are logged to `results.jsonl` each round. The best prompt (highest pass rate across all rounds) is written back to `prompt.txt` at the end.

### Setup

```bash
cd scripts
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # fill in API keys and model names
```

### Environment variables

| Variable | Description |
|---|---|
| `OPTIMIZER_MODEL` | Model for judging and rewriting (e.g. `gpt-4o`, `deepseek-chat`) |
| `EXECUTOR_MODEL` | Model for running the prompt under test (e.g. `gpt-4o-mini`) |
| `OPENAI_API_KEY` | API key |
| `OPENAI_BASE_URL` | Optional — override for OpenAI-compatible providers (e.g. DeepSeek) |

When `OPENAI_BASE_URL` is set, bare model names are automatically prefixed with `openai/` so litellm routes correctly.

### Run manually

```bash
# Write your initial prompt
echo "You are a helpful assistant." > prompt.txt

# Run optimization
python train.py "<intent>" prompt.txt data/test_cases.jsonl
```

`prompt.txt` is updated in place if a better prompt is found.
