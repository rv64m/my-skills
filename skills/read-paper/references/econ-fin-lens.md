# 金融 / 经济论文追问清单

用于 Phase 1（提问）和 Phase 5（审问）。按论文类型取用：因果推断类看 §1–2，资产定价 / 策略类看 §3–6。

与 ML 论文不同，这里的核心风险不是「涨点是否真实」，而是**相关性被当成因果**、以及**在纸面上有效的东西在真实市场里不存在**。

## 1. 识别策略（因果类论文的命门）

- 外生变异的来源到底是什么？用一句话说清：作者是靠什么把因果从相关里分离出来的？说不清，就说明识别策略不成立或没读懂。
- **DiD**：平行趋势可信吗？给了事前趋势图吗？处理时点交错（staggered）时用的是双向固定效应吗——那在异质处理效应下是有偏的。
- **IV**：相关性（第一阶段 F 统计量，弱工具变量？）和**排他性约束**分别怎么论证的？排他性无法检验，只能靠论证，作者的论证有多硬？
- **RDD**：带宽怎么选的？换带宽结果稳吗？断点处有没有操纵（McCrary 检验）？
- **固定效应**：加了哪些层级的固定效应？它吸收掉的到底是什么？残余变异还剩多少？
- 遗漏变量：什么样的未观测变量能同时驱动 X 和 Y？作者排除了吗？
- 反向因果的可能性排除了吗？

## 2. 数据与样本

- **幸存者偏差**：样本是否只含存续至今的公司 / 基金？退市回报计入了吗？
- **前视偏差（look-ahead bias）**：用的是 point-in-time 数据，还是经过后期修订（restated）的财务数据？基本面数据的**实际可得时点**（报告发布日而非财季末）对齐了吗？
- 样本期覆盖多少个完整周期？只覆盖一个 regime（如后金融危机的低利率期），结论的外部效度有限。
- 微型股 / 低价股（penny stocks）在样本里占多大权重？等权组合的收益经常由不可交易的极小市值股票驱动。
- 数据来源的已知问题（CRSP/Compustat 合并、分红调整、货币单位）处理了吗？

## 3. 统计推断

- **标准误怎么算的？** 面板数据里按公司 / 时间聚类（cluster）了吗？金融面板的横截面相关性极强，不聚类会严重低估标准误。
- 时序自相关：用了 Newey-West 吗？滞后阶数怎么定的？
- 用的是 Fama-MacBeth 还是混合 OLS？在这个场景下哪个更合适？
- **多重检验**：作者一共试了多少个设定？在因子研究里，考虑数据挖掘后的合理门槛远高于 t=2（文献中有 t>3 的建议）。这篇论文的 t 值经得起这个门槛吗？
- 样本内 vs 样本外的划分是真的，还是「样本外」期间作者已经知道结果？

## 4. 资产定价 / 因子研究

- alpha 是**相对于哪个模型**的？CAPM、FF3、FF5、q-factor 差别很大。相对越弱的基准模型，alpha 越容易显著。
- 控制了已知因子后还剩多少？这个信号会不会只是 value / momentum / quality 的重新包装？
- 收益集中在哪：多头还是空头？**集中在空头端的策略通常难以实现**（借券成本、卖空限制、可借量）。
- 集中在哪些股票：大盘还是小盘？小盘驱动的 alpha 容量有限。
- 收益在时间上是均匀的还是靠少数几个月？画了累计曲线吗？
- **发表后衰减**：如果这个信号在样本期后被公开，还存在吗？有没有用样本期外的数据检验？

## 5. 策略 / 回测类论文

- **交易成本**计入了吗？用的什么假设——固定 bp、买卖价差、还是含市场冲击的模型？换手率多少？成本翻倍后策略还活着吗？
- **容量**：这个策略能承载多少资金？作者讨论了吗？
- 再平衡频率、执行时点（收盘价成交？次日开盘？）现实吗？信号生成到执行之间留了时滞吗？
- 卖空可行性：借券费率、可借量、监管限制。
- **回测过拟合**：作者试了多少组参数？在有限样本上试足够多的策略必然能找到高 Sharpe。有没有做 deflated Sharpe ratio 之类的调整？
- 杠杆和风控假设：报的 Sharpe 是在什么杠杆和保证金假设下的？

## 6. 经济机制

- 有**经济学解释**吗，还是纯粹的数据规律？没有机制的规律更可能是数据挖掘的产物。
- 作者的解释是**风险补偿**还是**错误定价**？如果是风险，是什么风险、为什么投资者要求补偿？如果是错误定价，为什么套利者没有消除它（套利限制是什么）？
- 提出的机制有没有**独立的可检验推论**？作者检验了吗？这是区分真机制和事后叙事的关键。

## 7. 稳健性检验

- 稳健性检验是**挑出来展示的**吗？作者做了哪些、又可能做了哪些没报？
- 子样本（分时期、分市场、分规模）结果一致吗？某个子样本失效，作者怎么解释？
- 换定义、换度量、换筛选条件后结果稳吗？
- 有没有在**另一个市场 / 另一类资产**上复制？

## 8. 复现视角

- 数据是商业数据库（CRSP、Compustat、TAQ、WRDS）吗？没有订阅就无法复现，成本要写进笔记。
- 变量构造给到可实现的粒度了吗（会计科目、筛选条件、滞后期）？
- 代码 / 复现包公开吗？
- **最小可行复现**：能否用公开数据（如 Ken French 数据库、Yahoo）在小范围内复现核心结论的定性方向？

## 红旗清单

出现以下任一，在笔记 §5 明确记下：

- 因果措辞（"causes"、"leads to"、"效应"）但识别策略只是加控制变量
- 只报了含成本前收益，或成本假设明显偏低
- t 值刚好过 2，且论文显示作者试了很多设定
- 样本期在某个明显特殊的窗口起止
- 收益主要来自空头端或微型股，却不讨论可实现性
- 无经济机制解释，只有统计显著性
- 稳健性检验一律成功（真实数据几乎不会如此听话）
