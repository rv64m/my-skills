# AI / ML / CS 论文追问清单

用于 Phase 1（提问）和 Phase 5（审问）。不必逐条走完——挑与这篇论文主张相关的问。

方法类论文的失败模式高度集中：**涨点是真的，但归因是错的**。多数追问都是在分离「这个机制起作用」和「其他东西起作用」。

## 1. 基线公平性（最高频的问题所在）

- 基线和新方法的**算力预算**相同吗？参数量、训练步数、数据量对齐了吗？还是新方法悄悄多训了？
- **调参投入对称吗？** 作者为自己的方法搜了几十组超参、给基线用默认值，是最常见的不公平来源。论文里有没有交代双方的搜索协议？
- 对比的是**最强基线还是方便基线**？该领域当前 SOTA 是否被刻意略过、或只在附录里出现？
- 基线数字是**自己复现的还是抄原论文的**？抄来的数字往往来自不同的数据划分、预处理或评测协议，不可直接比较。
- 如果基线被复现得比原论文报告的差，作者解释原因了吗？

## 2. 增益是否真实

- 有没有**多个随机种子**？报了方差 / 置信区间吗？单种子的提升在很多任务上落在噪声范围内。
- 提升幅度相对于种子间波动是多少？如果 baseline 种子标准差是 0.5，提升 0.3 就没有意义。
- checkpoint 是怎么选的？在**测试集上选最优 checkpoint / 最优 epoch** 等于测试集泄漏。
- 正文里的数字与表格一致吗？「提升 40%」是绝对还是相对、在哪一列取得的？
- 定性样例是精选的吗？有没有展示失败案例？

## 3. 数据泄漏与评测污染

- 训练/预训练语料与评测集有重叠吗？大模型论文里这是默认存疑项，作者做去污染检查了吗？
- 时序数据：特征里有没有**用到未来信息**？划分是随机划分还是按时间划分？
- 同一测试集被整个社区反复使用多少年了？在其上的微小提升可能只是对测试集的集体过拟合。
- 数据预处理（归一化、筛样本、去异常值）是在划分前还是划分后做的？划分前做就是泄漏。

## 4. 消融能否支撑归因

- 消融是不是**一次只改一个东西**？一次动多处，功劳无法归因。
- 消融跑在**和主结果相同的设定**下吗？常见弱化：主结果在大模型上，消融在小模型上，然后声称机制一致。
- 有没有做**最关键的那个消融**——把声称的核心机制换成一个平凡实现（随机 / 恒等 / 均匀）？如果换成平凡实现效果不掉，机制解释就不成立。
- 有没有可能只是**参数量或正则化效应**？加了模块通常也加了参数。作者控制参数量了吗？

## 5. 主张的射程

- 声称「通用 / 更鲁棒 / 可扩展」，但只在几个数据集、一个模型规模、一种语言上验证？主张的范围应该收窄到证据支持的范围。
- **规模化声明**尤其要查：曲线只画到 1B 参数，却声称趋势延续到 100B——这是外推，不是证据。
- 分布外（OOD）测了吗？还是只有同分布测试集？
- 理论部分证明的对象，和实际实现的算法是同一个吗？常见做法是对一个大幅简化的版本证明性质，再暗示它适用于完整方法。

## 6. 代价与实用性

- 推理开销：延迟、显存、吞吐。只报 FLOPs 而不报实测墙钟时间，通常意味着实测不好看。
- 训练成本相对基线是多少倍？
- 有没有引入新的超参？敏感吗？敏感的超参意味着实际使用时需要重新搜，成本要计入。
- 工程复杂度：需要自定义 kernel、特殊硬件、多阶段流水线吗？

## 7. LLM / 生成式论文的额外追问

- **评测用的 judge 模型**与被评测模型是否同源？同族模型互评存在自偏好（self-preference）偏差。
- 人工评测：几个标注员？一致性（agreement）多少？标注员知道哪个是作者的方法吗？
- prompt 敏感性：结果在换一种 prompt 措辞后还成立吗？基线用的 prompt 是否被同等优化？
- 解码设置（temperature、top-p、采样次数）在各方法间对齐了吗？
- 报的是 pass@1 还是 pass@k？k 是多少，各方法是否一致？

## 8. 复现视角

- 超参**全部**给了吗（含学习率调度、warmup、weight decay、batch size、梯度裁剪）？
- 数据预处理与划分脚本可得吗？只给数据集名字不够。
- 代码是否公开、是否包含训练代码（很多只放推理代码）？
- 算力需求写清楚了吗？估一下按公开价格复现主实验的成本。
- **最小可行复现**：哪个最小实验能验证核心主张？通常不是主表，而是某个消融——先跑它，成本低且直击机制。

## 红旗清单

出现以下任一，在笔记 §5 明确记下：

- 无方差 / 单种子，且提升幅度很小
- 消融设定与主结果设定不一致
- 未公开代码 + 未给完整超参
- 只与弱基线比较，回避当前 SOTA
- 主张范围明显宽于实验覆盖范围
- 只报相对提升（「提升 40%」）而不给绝对数值
- 「由于篇幅限制」省略了关键实验细节
